# R1-T015: Earcut triangulation backend

Status: VERIFIED
Owner: Cursor
Reviewer: Cursor
Branch: main

## Specification requirements

- MESH-004 FaceId mapping on derived triangles
- Existing `triangulatePolygon` contract preserved for simple polygons
- Earcut only in `@modeling-kit/mesh`

## Goal

Add Earcut behind the existing triangulation contract for concave polygons, holes, multiple loops, and extruded caps. Keep ear clipping for convex loops. Validate before and after; treat suspicious output as failure.

## Dependencies permitted

- `earcut` 3.0.2 in `@modeling-kit/mesh` only
