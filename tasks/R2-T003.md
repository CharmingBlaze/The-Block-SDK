# Task R2-T003 — Attribute propagation service

**State:** DRAFT  
**Phase:** 2 (Correctness foundation)  
**Allowed packages:** `@modeling-kit/mesh` — `packages/mesh/src/internal/` and `packages/mesh/src/operations/` only  
**Forbidden:** validation (consume only), commands, selection, tools, three-adapter, sdk, new npm dependencies  
**Depends on:** R2-T001, R2-T002

---

## Goal

Replace the per-operator ad-hoc attribute copying with a single `AttributePropagationService`. Each operator declares an `AttributePolicy`; the service handles all attribute types: UVs (single + multi-channel), normals, vertex colors, material slots, edge seams, edge creases, skin weight hooks.

---

## Acceptance criteria

1. `AttributePropagationService` interface and `createAttributePropagationService(mesh)` factory exported from `packages/mesh/src/internal/attribute-propagation.ts`.
2. `AttributePolicy` type exported alongside:
```ts
export type AttributePolicy = {
  readonly uv: "copy" | "interpolate" | "project" | "reject";
  readonly normals: "copy" | "recalculate" | "interpolate";
  readonly seams: "preserve" | "split" | "clear";
  readonly creases: "preserve" | "interpolate" | "clear";
  readonly materialSlots: "inherit" | "split" | "reject";
};
```
3. `AttributePropagationService` interface:
```ts
export interface AttributePropagationService {
  /** Copy/split attributes from one corner to a newly created corner. */
  splitCorner(source: CornerId, target: CornerId, policy: AttributePolicy): void;
  /** Interpolate attributes for a new vertex inserted at parameter t on an edge. */
  interpolateEdge(edge: EdgeId, t: number, policy: AttributePolicy): CornerAttributes;
  /** Duplicate all corner attributes from sourceFace to targetFace (same vertex order). */
  duplicateFace(sourceFace: FaceId, targetFace: FaceId, policy: AttributePolicy): void;
  /** Remap attributes after a topology operation using the provided TopologyMapping. */
  remap(mapping: TopologyMapping, policy: AttributePolicy): void;
}
```
4. `MeshOperationContext.attributeService` field added (typed as `AttributePropagationService`). The `runTransactionalMeshOp` helper creates the service from the mesh before executing the operation callback.
5. Migrate these operators to use the service instead of hand-rolling attribute copies:
   - `packages/mesh/src/operations/bevel/attributes.ts` → `transferEdgeAttributes` delegates to service
   - `packages/mesh/src/operations/extrude-faces.ts` → UV/normal/seam/crease propagation
   - `packages/mesh/src/operations/inset-faces.ts` → UV interpolation on inset corners
   - `packages/mesh/src/operations/loop-cut.ts` → UV interpolation at cut parameter `t`
6. The existing `cloneCornerAttributes` and `interpolateCornerAttributes` in `corner-attributes.ts` are kept as internal helpers (used by the service implementation) but not called directly from operators.
7. Test file `packages/mesh/src/__tests__/attribute-propagation.test.ts`:
   - Extrude a UV-mapped face → extruded corners preserve UVs (policy `"copy"`)
   - Loop cut at t=0.5 on a UV-mapped edge → new corner UVs are interpolated (policy `"interpolate"`)
   - Bevel a seam edge with `seams: "preserve"` → new chamfer edge inherits seam flag
   - Bevel a crease edge with `creases: "interpolate"` → crease weight interpolated by t
   - Multi-channel UV (`uvChannels`) preserved through extrude

---

## Implementation notes

- `project` UV mode is a stub for now: log a warning and fall back to `"copy"`. Do not implement projection geometry yet.
- `recalculate` normals mode: compute face normal from position data, assign to all corners. Use the existing `Vector3` math.
- For `remap`: iterate `mapping.vertices`, `mapping.faces`, `mapping.corners` and copy/interpolate attributes based on the mapping's source arrays.
- Skin weight hook: `splitCorner` and `interpolateEdge` accept an optional `WeightInterpolator` callback so rigging can be wired in later without changing this interface.
