## Goal

Extend `validateMesh()` into a fully guarded `validateMeshInvariants()` that walks raw records directly (never calling high-level query methods that can throw on corrupt meshes). Inject it into dev-build post-op assertions.

---

## Acceptance criteria

1. `validateMeshInvariants(mesh, options?)` is exported from `@modeling-kit/validation` and returns `MeshInvariantReport`.
2. Existing `validateMesh()` is preserved as a deprecated alias for backwards compatibility.
3. New raw-record checks (all guarded — never throw, only push errors):
   - Every `HalfEdgeRecord.next` resolves to an existing half-edge record → `"BROKEN_NEXT_LINK"`
   - Every `HalfEdgeRecord.prev` (if stored) resolves → `"BROKEN_PREV_LINK"`
   - Every `HalfEdgeRecord.twin` (if set) resolves, and `twin.origin === he.next.origin` for the reverse pair → `"BROKEN_TWIN_LINK"`
   - Every face's starting half-edge walks back to itself in ≤ `face.vertices.length + 1` steps → `"BROKEN_FACE_LOOP"`
   - Every `CornerRecord.faceId` resolves to an existing face → `"ORPHANED_CORNER"`
   - Every `CornerRecord.vertexId` resolves to an existing vertex → `"ORPHANED_CORNER"`
   - No two half-edges share the same `(origin, destination)` directed pair → `"DUPLICATE_DIRECTED_EDGE"`
4. New `MeshIssueCode` values added to `types.ts`: `"BROKEN_NEXT_LINK"`, `"BROKEN_PREV_LINK"`, `"BROKEN_TWIN_LINK"`, `"BROKEN_FACE_LOOP"`, `"ORPHANED_CORNER"`, `"DUPLICATE_DIRECTED_EDGE"`.
5. `GeometryTolerance` interface exported from `@modeling-kit/validation` (re-use from mesh or define inline).
6. `assertStrictMesh` in `packages/mesh/src/internal/assert-mesh.ts` calls `validateMeshInvariants` in development (`process.env.NODE_ENV !== 'production'`) and throws a descriptive error listing the first 5 issues if `!report.valid`.
7. Test file `packages/validation/src/__tests__/invariants.test.ts`:
   - After `MeshBuilder.createCube(1)` → `valid: true`
   - After `extrude`, `bevel`, `loopCut`, `inset`, `subdivide` on a cube → each passes `validateMeshInvariants`
   - Manually corrupt a mesh (set a half-edge's `next` to a nonexistent ID) → validator catches `"BROKEN_NEXT_LINK"`
   - Manually corrupt twin link → `"BROKEN_TWIN_LINK"`
   - Orphaned corner → `"ORPHANED_CORNER"`

## Implementation notes

- Use `mesh.halfEdges.get(id)` directly, not `mesh.getFaceVertices()` — the latter can throw on a broken loop.
- Guard every `.get()` call: if it returns `undefined`, push an error and `continue` — do not let the validator itself throw.
- The directed-edge uniqueness check: build a `Set<string>` of `"${he.origin}->${destination}"` strings while iterating `mesh.halfEdges`. Push `"DUPLICATE_DIRECTED_EDGE"` on collision.
- The face-loop check: walk `he = mesh.halfEdges.get(he.next)` up to `faceVertexCount + 1` steps; if not back to start, push `"BROKEN_FACE_LOOP"`.
- `strictManifold: true` (default) promotes `NON_MANIFOLD_EDGE` and `NON_MANIFOLD_VERTEX` from warnings to errors.
