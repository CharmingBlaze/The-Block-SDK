# R1-T017: meshoptimizer derived-triangle service

Status: VERIFIED
Owner: Cursor
Reviewer: Cursor
Branch: main

## Specification requirements

- Operate only on triangulated render/export data
- Never replace HalfEdgeMesh
- Expose mapping limitations when simplification drops triangles
- Cancellable jobs, stale revision checks, dispose, limits

## Goal

Optional `@modeling-kit/meshopt` wrapping meshoptimizer for vertex-cache/fetch reorder, index reorder, and controlled LOD simplification.

## Dependencies permitted

- `meshoptimizer` 1.2.0 in `@modeling-kit/meshopt` only

## Public API changes

New package. No required SDK dependency.

- `optimizeDerivedTriangles` / `MeshoptOptimizer.run`
- `MeshoptJobResult` with mapping status `exact` | `partial` | `none`

## Lifecycle

Job machine: queued → running → cancelling/completed/failed → disposed. Lazy WASM. No result cache.
