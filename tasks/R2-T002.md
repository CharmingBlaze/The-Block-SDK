# Task R2-T002 — MeshBuilder atomic rollback

**State:** DRAFT  
**Phase:** 2 (Correctness foundation)  
**Allowed packages:** `@modeling-kit/mesh` — `packages/mesh/src/builder.ts` only  
**Forbidden:** validation, commands, selection, tools, three-adapter, sdk, new npm dependencies  
**Depends on:** R2-T001 (use `validateMeshInvariants` in test assertions)

---

## Goal

Make `MeshBuilder.addFace()` truly atomic. If anything fails mid-insertion (duplicate directed edge, non-manifold third face in strict mode, any record creation error), the mesh must be byte-identical to its state before the call began. Currently records are inserted incrementally — a failure at edge 3 of 4 leaves partial state.

---

## Acceptance criteria

1. `addFace()` stages all new records (vertices touched, edge records, half-edge records, corner records, face record, half-edge twin patches) into local staging arrays **before** writing to `mesh.vertices`, `mesh.edges`, `mesh.halfEdges`, `mesh.corners`, `mesh.faces`.
2. Only after all staging succeeds (no `throw`) does the method commit all staged records in a single loop.
3. On any validation failure: no staged record is written; existing twin links on previously-existing half-edges are not modified; method throws the original error.
4. A new `validateFaceInsertion(mesh, request): Result<void, MeshIssue[]>` pure function is exported (used by `addFace` and callable externally for preflight UI feedback):
   - All referenced vertices exist
   - No duplicate vertices in the same face (not just consecutive)
   - No consecutive duplicate vertices
   - No duplicate face ID
   - No duplicate directed edge (`(from, to)` pair already exists in `mesh.halfEdges`)
   - No third face attached to an edge in strict-manifold mode
   - Face area above tolerance
   - All positions finite
   - Attribute arrays match corner count (uvs, normals, colors, uvChannels, pinnedUvChannels)
5. `Result<T, E>` type used: `{ ok: true; value: T } | { ok: false; error: E }` — define inline in builder.ts or import from `@modeling-kit/core` if one already exists.
6. New test file `packages/mesh/src/__tests__/builder-atomic.test.ts`:
   - Build a valid cube → 6 faces committed, mesh valid
   - Attempt a 7th face referencing a non-existent vertex → throws, mesh still has 6 faces
   - Attempt a face that would add a non-manifold edge (3rd face on edge) in strict mode → throws, mesh unchanged
   - Attempt a face with duplicate directed edge → throws, mesh unchanged
   - Verify with `validateMeshInvariants` after each failed insertion that mesh is valid

## Staging strategy

```ts
interface StagedFaceInsertion {
  faceRecord: FaceRecord;
  edgeRecords: EdgeRecord[];           // new edges only
  halfEdgeRecords: HalfEdgeRecord[];   // new half-edges only
  cornerRecords: CornerRecord[];
  twinPatches: Array<{ heId: HalfEdgeId; twinId: HalfEdgeId }>; // existing HEs that need twin set
  undirectedEdgeKeys: Array<[VertexId, VertexId, EdgeId]>;
  directedHeKeys: Array<[VertexId, VertexId, HalfEdgeId]>;
  edgeFaceCountIncrements: EdgeId[];
}
```
