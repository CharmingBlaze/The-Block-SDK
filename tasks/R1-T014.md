# R1-T014: Primitive-geometry adapter

Status: VERIFIED
Owner: Cursor
Reviewer: Cursor
Branch: main

## Specification requirements

- PRIM generators remain conversion-only; `HalfEdgeMesh` is the editable source of truth
- Corner UVs/normals, seams, and hard-normal boundaries must survive conversion
- Three.js `BufferGeometry` stays derived and disposable
- Commands + exact undo restore document and selection
- Dependency policy: `primitive-geometry` in `@modeling-kit/primitives` behind `convertSimplicialComplex`

## Goal

Typed adapter from `primitive-geometry` positions/normals/UVs/cells into the canonical half-edge mesh. Support the library primitives that add value beyond the modeling generators (rounded cube, ellipsoid, squircles, platonic solids, annulus, etc.). Do not make library arrays editable.

## Current verified behavior

- Modeling box remains 8/12/6 quads (`generateBox`)
- `CreatePrimitiveCommand` already persists generated meshes with undo
- `ThreeViewportAdapter` rebuilds and disposes derived geometry

- `packages/primitives/src/library/**`

## Forbidden files

- `packages/mesh/src/half-edge-mesh.ts` kernel rewrite
- Minecraft / game formats
- New state machines for static conversion

## Existing APIs to reuse

- `MeshBuilder`, `validateMesh`, `triangulateMesh`, `serializeMesh`
- `CreatePrimitiveCommand` persist/undo path
- `ThreeViewportAdapter` derived geometry
- `ModalToolSession` only if interactive placement already exists (not required for static conversion)

## Dependencies permitted

- `primitive-geometry@2.11.0` in `@modeling-kit/primitives` only

## Implementation constraints

- Headless primitives package: no `three`, no DOM
- Do not blindly weld coincident render vertices across UV/normal seams
- Reject invalid attribute lengths, indices, non-finite values, zero-area output transactionally
- Winding and outward normals must match SDK conventions
- Keep face-to-triangle mapping via `triangulateMesh`

## Acceptance criteria

- Every supported library id converts, validates, triangulates, and round-trips serialize
- Checker-texture gallery lists all supported primitives with wireframe and flat/smooth shading
- Undo/redo of a library primitive restores the document
- Adapter dispose drops derived Three.js geometry

## Lifecycle requirements

- Static conversion: no state machine, no workers, no caches
- Three.js ownership remains the adapter (`dispose` of regenerated BufferGeometry)
