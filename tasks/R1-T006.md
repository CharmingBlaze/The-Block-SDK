## Goal

`TransformGesture` must use `@modeling-kit/core` `OperationLifecycleMachine` (idle → beginning → transforming → committing → completed; transforming → cancelling → cancelled). Illegal transitions throw. Cancel after transforming restores baseline (already `restoreBaseline`).

## Existing APIs

- `OperationLifecycleMachine`, `canTransitionOperation` in `packages/core/src/lifecycle.ts`
- `TransformGesture` in `packages/transform/src/gesture.ts`
- Tests in `packages/core/tests/lifecycle.test.ts` and `packages/transform/tests/transform.test.ts`

## Allowed files

- `packages/transform/src/gesture.ts`
- `packages/transform/src/index.ts` (export lifecycle state getter only if needed)
- `packages/transform/tests/transform.test.ts`

## Forbidden

commands, snapping, mesh operators, new dependencies.

## Behavior

- Constructor: `idle` → `beginning` → `transforming` (or stay beginning until first `update`).
- `update`: legal only in `beginning` or `transforming`; then `transforming`.
- `commit()` new method or document that callers currently apply via session: add `commit()` that goes `transforming` → `committing` → `completed`. If session already commits elsewhere, `commit()` only advances the machine after a meaningful change; no-op completed.
- `restoreBaseline` / cancel: `transforming` → `cancelling` → `cancelled`. Second cancel is illegal.
- `completed`/`cancelled` reject `update`.

Do not change math of translate/rotate/scale.

## Acceptance tests

1. Existing parent-space translate and selection-roots tests still pass.
2. After `restoreBaseline`, `update` throws `IllegalLifecycleTransitionError`.
3. `commit()` then `update` throws.
4. Construct → `restoreBaseline` without `update` is allowed (beginning → cancelling → cancelled) or documented as idle cancel.
