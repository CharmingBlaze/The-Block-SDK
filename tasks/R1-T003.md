## Goal

Mesh-editing commands must (1) apply `TopologyMapping` to selection via `SelectionManager.applyRemap` plus post-op suggestion, and (2) restore the pre-command `SelectionSnapshot` on `undo`. Today `ExtrudeFacesCommand.undo` restores mesh only; execute uses `selection.replace` of cap ids without remapping leftovers.

## Prerequisites

May land in parallel with T001/T002. Use **existing** `TopologyMapping` and `applyRemap`. Do not wait for grow/shrink. If an operator overload does not return mapping, call the `MeshOperationContext` overload (see `extrudeFaces` in `operations/extrude-faces.ts`).

## Behavior

Helper `applyTopologySelection(selection, objectId, mapping, suggestion)`:

1. `applyRemap` using deleted sets and `replacedBy` first-id (or all ids if 1:n — include all replacements in `map` as first target plus add created if needed).
2. If `suggestion.elementIds.length > 0`, `replace` domain from suggestion with those ids (canonical post-op selection).
3. Drop ids not in mapping and not in suggestion.

Each listed command:

- Before mutate: `selectionBefore = context.selection.snapshot()`
- After mutate: apply helper with operator `mapping` + `selection`
- `undo`: restore mesh **and** `context.selection.restore(selectionBefore)` and emit `selection:changed`

Do not add new npm deps. Do not change fluent API.

## Acceptance tests (add to `commands.test.ts`)

1. Cube → select one face → extrude → selection is cap face(s) only → **undo → selection is original face id** and mesh fingerprint restored.
2. Redo after that restores cap selection.
3. Select two faces, delete-equivalent: dissolve or cut not required; for **splitEdge**: select the original edge, split, selection contains new edges/vertex per command suggestion; undo restores original edge id.
4. After extrude, a stale extra face id that was in elementIds but deleted by the op is not present (use mapping.deleted). If extrude does not delete the original face id, assert original face is not still selected unless it is the cap (cube extrude typically deletes original and creates cap — assert original id absent).

Run: `pnpm exec vitest run packages/commands/tests/commands.test.ts`
