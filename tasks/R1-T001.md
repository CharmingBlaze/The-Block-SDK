## Behavior

### `addVertex(mesh, { position }, ctx)`

Creates an isolated vertex. Mapping: vertex `created`. Selection suggestion: that vertex.

### `addEdge(mesh, { a, b }, ctx)`

Creates a boundary edge between two existing vertices if they do not already share an edge. Reject if vertices missing, `a === b`, or edge exists. Do not invent faces.

### `addFace(mesh, { vertexIds, materialSlot? }, ctx)`

Creates a face from ≥3 existing vertices in order (CCW). Reuse `MeshBuilder.addFace` or equivalent kernel path. Reject duplicate consecutive vertices, missing IDs, <3 verts. Mapping records new face, edges, corners.

### `deleteFaces(mesh, { faceIds }, ctx)`

Public wrapper around face deletion with mapping (`deleted` faces/corners; edges deleted when they become unused). Reject unknown IDs. Empty `faceIds` is no-op success. Must not leave dangling half-edges.

### `deleteEdges(mesh, { edgeIds }, ctx)`

Delete listed edges. Incident faces that used the edge are deleted (documented policy: **edge delete dissolves incident faces**). Mapping complete. Reject unknown IDs.

### `deleteVertices(mesh, { vertexIds }, ctx)`

Delete listed vertices and all incident faces/edges. Isolated vertices delete cleanly. Mapping complete.

All operators: on validation failure, **mesh unchanged** (clone-check or mutate-after-validate). `validation: "strict"` throws or returns via throw — match existing operators (`splitEdge` style: throw `RangeError` / `ModelingKitError`).

Do not implement dissolve/collapse/separate/join.

## Acceptance tests (`packages/mesh/tests/elements.test.ts`)

1. addVertex then addFace on a new triangle; `validateMesh` valid; mapping created counts match deltas.
2. addEdge between two verts of an existing open edge mesh / or two isolated verts; reject duplicate edge.
3. deleteFaces on one cube face: five faces remain; mapping.faces.deleted has the id; no dangling refs (`validateMesh` no error codes for missing refs).
4. deleteVertices on a cube corner: incident faces gone; remaining topology validates or reports only expected boundary issues, never missing IDs.
5. deleteEdges on a shared cube edge: both incident faces removed; mapping lists those faces deleted.
6. Unknown id throws; fingerprint/serialize of mesh equals pre-call clone.
7. `replacedBy` / `deleted` / `created` disjoint for faces on deleteFaces.

Run: `pnpm exec vitest run packages/mesh/tests/elements.test.ts packages/mesh/tests/operations.test.ts packages/mesh/tests/mesh.test.ts`
