# R1-T016: geometry-extrude profile adapter

Status: VERIFIED
Owner: Cursor
Reviewer: Cursor
Branch: main

## Specification requirements

- Profile → validate → adapter → HalfEdgeMesh → validate → command commit
- Preserve positions, normals, UVs as corner attributes
- Reuse `ModalToolSession` for draw/preview/commit/cancel
- No second mesh or competing extrusion kernel

## Goal

Add a headless profile-extrusion adapter for drawn 2D profiles, floors, walls, thick paths, holes, and bevels. Canonical mesh stays editable source of truth.

## Dependencies permitted

- `geometry-extrude` 0.2.1 in `@modeling-kit/primitives` only

## Existing APIs to reuse

- `convertSimplicialComplex`, `persistGeneratedPrimitive`
- `triangulatePolygonLoops` for unusable-polygon reject
- `ModalToolSession` / `OperationLifecycleMachine`
- `CreateLibraryPrimitiveCommand` persistence pattern

## Public API changes

Additive:

- `generateProfileExtrude`, `generateFloor`, `generateWallPath`, `ProfileExtrudePreview`, profile types
- `ExtrudeProfileCommand`
- `FluentEditor.spawn.profile` / `spawn.floor` / `spawn.wallPath`
- `ProfileDrawTool`

## Lifecycle

- Conversion: pure function
- Drawing: existing `ModalToolSession`
- Preview: `ProfileExtrudePreview` replaces kernel refs; hosts dispose Three.js geometry
