## Goal

Extend `@modeling-kit/selection` so 3D vertex/edge/face selection can invert, grow, shrink, select linked, edge loop, edge ring, and boundary. UV grow/shrink in `@modeling-kit/uv` is **not** this work — do not copy UV types into 3D selection.

## Behavior

Pure functions taking `(mesh, snapshot) => next element ids` plus manager methods that no-op when domain is `object` / `none` / `uv` / `bone` / `keyframe`.

| Method | Domain | Behavior |
| ------ | ------ | -------- |
| `invert(mesh)` | vertex/edge/face | All elements of that kind minus current |
| `selectAll(mesh)` | vertex/edge/face | All ids of domain |
| `grow(mesh)` | face | add adjacent faces; vertex: add verts of incident faces of current verts; edge: add edges sharing a vertex |
| `shrink(mesh)` | inverse of one grow step on the current set (elements that still neighbor a non-selected element of the same domain stay; classic: remove boundary of selection) | Document in code comment; test on a 2x2 quad grid of faces |
| `selectLinked(mesh)` | flood via adjacency of current domain |
| `selectEdgeLoop(mesh)` | domain edge; quad traversal across opposite edges; stop at poles/triangles/boundary; include start |
| `selectEdgeRing(mesh)` | domain edge; adjacent quads’ opposite edges |
| `selectBoundary(mesh)` | if domain face: faces with a boundary edge; if edge: `findBoundaryEdges`; if vertex: verts on boundary edges |

Unknown mesh elements in selection are dropped when running topology ops.

Do not implement box/lasso/x-ray/similar/material.

## Acceptance tests

Use `MeshBuilder.createCube` and a 2x2 grid of quads (`generateGrid` from primitives **forbidden** — build with MeshBuilder in the test).

1. invert face selection on cube: 1 selected → 5 selected.
2. selectAll vertices on cube: 8.
3. grow faces on cube from one face: 4 adjacent (not the opposite).
4. shrink after grow returns toward original (exact set asserted).
5. selectLinked from one face on cube: all 6 (connected).
6. Two disconnected faces (two triangles not sharing verts): selectLinked does not jump.
7. selectEdgeLoop on a cube equator-like loop (4 edges) if topology allows; otherwise assert termination on a plane grid of quads (closed loop of 4).
8. selectBoundary on a plane (one quad): 4 edges.
9. grow on domain `object` does not throw and does not change snapshot.

Run: `pnpm exec vitest run packages/selection/tests`
