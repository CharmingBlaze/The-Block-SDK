# Geometry gallery

Checker-texture fixture for library primitives (`generateLibraryPrimitive`). Shows wireframe plus flat/smooth shading through `createThreeViewport`. Preview materials and wires are disposed on shape change and `pagehide`.

```bash
pnpm --filter @modeling-kit/geometry-gallery dev
```

Canonical vs library ingest: [`docs/guides/primitive-geometry.md`](../../docs/guides/primitive-geometry.md). Other hosts: [`docs/guides/examples.md`](../../docs/guides/examples.md).
